### 이미지 교체 방법

1. 표의 **파일명 그대로** `assets/images/simmons/`에 덮어쓰면 HTML 수정 없이 반영됩니다. 칸마다 파일이 따로 있어서 한 칸을 바꿔도 다른 칸에는 영향이 없습니다.
2. 파일명이나 확장자를 바꾸면 `index.html`의 `src="assets/images/simmons/…"` 경로를 함께 수정합니다. (6번 `intro.jpg`만 `sections.css`의 `.intro-bg`에 경로가 있습니다.)
3. 사진과 팝업은 **JPG**, 로고·퀵메뉴 아이콘은 **투명 PNG**로 만들고 표의 **목표 용량** 이하로 맞춥니다.
   - Photoshop·Figma에서 내보낸 JPG는 용량이 큰 편이므로 [squoosh.app](https://squoosh.app)에서 MozJPEG **품질 75~80**으로 한 번 더 압축하세요. (같은 크기라도 400KB → 80KB 정도로 줄어듭니다.)
   - 사진을 PNG로 넣거나 권장 크기보다 훨씬 크게 넣으면 **스크롤할 때 버벅입니다.**
4. 교체 후 **1920 · 1440 · 1024 · 768 · 390px** 너비에서 크롭과 텍스트 가독성을 확인합니다.

### 이미지가 아니라 코드로 그린 것

- **카카오톡 버튼**: `index.html`의 `<svg class="kakao-mark">`(말풍선·TALK 글자), 크기·색은 `layout.css`의 `.kakao-mark`.
- **팝업 3번 WELCOME 10% 쿠폰**: 숫자·문구는 `index.html`의 `.coupon`, 색·크기는 `popup.css`.
- **팝업 문구**(구분 문구·제목·설명·할인/대상 등): 모두 `index.html`의 `<aside class="event-popup">` 안에 있습니다.

11~14번 사진과 문구는 [시몬스 공식 블로그](https://blog.naver.com/simmonskorea)의 글(프리즈 서울 아트 퍼포먼스, 팩토리움, LIFE IS COMFORT 캠페인, 테라스 체험존, 신세계 강남점, 슬립라운지), 팝업 1번은 블랙 시몬스 데이 글을 바탕으로 2026-10-08에 정리했습니다.

## 3. 여백

여백 값은 **`base.css` 맨 위 `:root`의 변수**에서 한 번에 조절합니다.

| 변수            | 의미                           | 값                                                                 |
| --------------- | ------------------------------ | ------------------------------------------------------------------ |
| `--pad`         | 화면 좌우 여백                 | `clamp(24px, 4.2vw, 72px)`, 600px 이하 20px                        |
| `--section-y`   | 섹션 위아래 여백               | `clamp(100px, 12vw, 190px)`, 1100px 이하 90px, **600px 이하 48px** |
| `--heading-gap` | 모바일에서 섹션 제목 아래 여백 | 28px                                                               |

프로모션 ↔ 좋은 밤 기준 사이는 일부러 좁게 붙여 두었습니다(`sections.css`의 `.promotions` 아래쪽 · `.intro` 위쪽 여백).

## 4. 움직임·동작 설정

| 바꾸고 싶은 것                           | 위치                                      |
| ---------------------------------------- | ----------------------------------------- |
| 히어로 자동 넘김 간격 (5.2초)            | `main.js` 4번의 `5200`                    |
| 기술 슬라이드 자동 넘김 (5초)            | `main.js` 5번의 `5000`                    |
| 매장 카드 자동 넘김 (모바일, 3.8초)      | `main.js` 6번의 `3800`                    |
| 팝업 슬라이드 시간 (5초)                 | `popup.css`의 `--popup-duration`          |
| 팝업이 뜨는 시점 (0.6초 후)              | `main.js` 7번 맨 아래 `600`               |
| 팝업 하단 바 높이 (PC 40px, 모바일 44px) | `popup.css`의 `--popup-footer`            |
| 맨 위로 버튼 (모바일에서 숨김)           | `layout.css` Quick menu의 600px 이하 규칙 |

- 자동 넘김은 화면에 보일 때만 돌아가고, 마우스를 올리거나 키보드로 조작하면 멈춥니다. 기기에서 '동작 줄이기'를 켠 사용자에게는 자동 넘김을 하지 않습니다.
- 팝업 **"오늘 하루 보지 않기"**를 누르면 그날 자정까지 팝업이 뜨지 않습니다. 테스트 중 다시 보려면 개발자 도구 콘솔에서 `localStorage.removeItem("simmons-popup-hidden-until")` 실행 후 새로고침하세요.
- 포트폴리오용이라 링크·뉴스레터·퀵메뉴는 어디로도 이동하지 않습니다(`main.js` 9번). 실제 연결 시 이 부분만 바꾸면 됩니다.
